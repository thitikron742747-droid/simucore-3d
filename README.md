# SimuCore 3D

ห้องแล็บเครือข่ายจำลอง 3D — เว็บแบบ static เปิดได้จากเบราว์เซอร์โดยไม่ต้องมีเซิร์ฟเวอร์

## แชร์ให้คนอื่นเข้าดู (GitHub Pages)

1. รวม (merge) โค้ดเข้า branch `main`
2. ไปที่ **Settings → Pages** ของ repo
3. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที เว็บจะออนไลน์ที่
   `https://thitikron742747-droid.github.io/simucore-3d/`

### ลิงก์สำหรับแชร์

```
https://thitikron742747-droid.github.io/simucore-3d/index.html?guest=1
```

ลิงก์ที่มี `?guest=1` จะพาคนที่เปิดเข้าหน้าหลักทันทีในฐานะ **ผู้เยี่ยมชม** ไม่ต้องสมัครหรือเข้าสู่ระบบ
(ปุ่ม **แชร์หน้านี้** ในหน้าหลักจะคัดลอกลิงก์นี้ให้อัตโนมัติ)

> ข้อมูลโครงการเก็บในเบราว์เซอร์ของแต่ละคน (`mode: 'local'` ใน `config.js`) คนที่เปิดลิงก์จะไม่เห็นงานของเรา และงานของเขาไม่ปนกับของเรา
> ถ้าไม่อยากให้เข้าแบบผู้เยี่ยมชม ตั้ง `allowGuest: false` ใน `config.js`
